# موقع زكريا باحاج — التشغيل والنشر

## التشغيل محليًا
1. ثبّت Node.js 20+ ثم: `npm install`
2. ملف `.env.local` جاهز (نسخة من `.env.example` بقيمك). لا ترفعه إلى GitHub.
3. `npm run dev` ثم افتح الرابط الظاهر. لوحة التحكم: `الرابط/#/admin`

## الإدارة
سجّل الدخول بحسابك المضاف إلى جدول `admins`. من اللوحة: المشاريع (إضافة/تعديل/حذف بتأكيد، مسودة/نشر، رفع صورة)، وإعدادات الموقع (العبارة، النبذة، البريد، الروابط الاجتماعية بصيغة `الاسم|الرابط`).

## النشر (Vercel/Netlify/Cloudflare Pages)
- الأمر: `npm run build` — المجلد: `dist`
- أضف المتغيرين `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في إعدادات الاستضافة.
- في Supabase: Authentication ← URL Configuration، ضع رابط موقعك.

## تعديل الهوية
الألوان في أعلى `src/styles.css` (متغيرات CSS). النصوص الافتراضية في `src/lib.ts`.

## الصفحات
`#/` الرئيسية — `#/work` كل الأعمال — `#/admin` الإدارة. المشاريع «المميزة» (حتى 2) تظهر في الرئيسية.
